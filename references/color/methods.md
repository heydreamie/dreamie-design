# 从颜色关系到可验收方案

示例数值用于说明设计决策，不是通用品牌色板。颜色数值、素材与验证要求见 [sources.md](sources.md)。

## 1. 先把意象转成可比较的条件

配色服从内容、目的和受众。意象词用于构造候选方向，需通过同内容比较确认。

**综合执行：** 用一句话写“谁在什么场景，先注意什么，接着读什么／做什么”。把“春天、文化、亲切”拆成可观察条件，例如植物图形与偏暖浅背景表现季节，正文保留清楚的深浅差，报名入口成为唯一最高优先级。不要从“亲子”直接推导粉色，也不要把“高级”自动等同黑金。

已有品牌规范先识别哪些不可变、哪些可扩展。无规范时，为每个方向写出颜色关系和预计效果，并用同一份内容试排，避免同时改图片、文案和布局后把结果全归因于颜色。

## 2. 决定统一路径，区分色名、属性与角色

区分大面积主色与整幅共同主调，以及相近色相、相近色调和细微浓淡。同名颜色在不同资料中未必相同。

| 画面条件 | 可试路径 | 重点检查 |
| --- | --- | --- |
| 有大背景或明确品牌色 | 以主色统领，配合衬托与文字色 | 背景是否抢过主体；品牌色能否承担该尺寸文字 |
| 多个近等面积模块／展品 | 统一明暗和彩度范围，允许多色相 | 局部有差异，整体仍同调；不强塞单一主色 |
| 图片或复杂花样占主要面积 | 降低细节观察综合色，再用纯色呼应或对照 | 把所有主要图片计入；文字局部背景另测 |
| 需要强烈区分或活跃印象 | 互补、对照或多色构造为候选 | 同时调明暗／彩度；区分类别而不破坏阅读 |

“明度／亮度”“彩度／饱和度”的术语在不同理论和软件中有不同定义；色调图、RYB画家色环、RGB/HSL、印刷原色不是同一坐标系统。用哪个系统要写清楚，不能把图上的三角、四边形直接当成所有软件固定角度必然好看的公式。

**综合交付表：** `角色｜颜色空间和数值｜具体位置｜面积或强弱关系｜可搭配背景／前景｜禁用组合｜出处或自拟说明`。静态物料可按用途精简；界面还需把默认、悬停、聚焦、选中、错误等映射回UI规范。照片本来就含许多颜色，背景／主体／强调角色也可各含多色。面积比例从真实内容试排得出；25/70/5、60/30/10等常见比例均只能作探索起点。

## 3. 四个可执行的调整手柄

1. **明暗与彩度：** 相近色太糊时增大必要边界的明暗差；互补色刺激过强时降低一方或双方彩度、调整明暗。不要只换色相。
2. **面积：** 小样合适的颜色铺满页面可能压住主体。先缩小强色面积或降低背景强度，再判断是否要换色。多数近等面积的色块也可以统一主调，不一定要改成主辅点三块。
3. **分隔：** 近似色边界不清或强对比相撞时，试留白、边线、中性色带或明暗不同的同系色。检查分隔宽度在最终尺寸是否仍可见；它会改变形状与整体印象，不能无限加粗。
4. **强调的位置和次数：** 一处强调能聚焦，多处分布能引导路径；多处强调仍要有一致关系和优先级。强调色可以是黑白或相近但可辨的颜色，并非必须高饱和互补。分类色不必全部变为抢眼强调色。

改变一项后，回到同一真实样张比较。单独色块不能证明文字、海报或页面已经合适。

## 4. 照片、渐变与纹样

照片取色与整体色调呼应可统一画面，但同色叠字容易融入背景。综合色还受图片、面积、纹样粗细和渐变影响；颜色差异不能弥补阅读层级问题。

**综合执行：** 保留重要照片的真实含义，必要时统一不相关图片的色调、分组或调整外围纯色。叠字检查字形覆盖区域内最不利的背景，不只取一处平均色。可调整裁切、换文字区域、增加适当底色／遮罩或改用独立文字区，再复查；不默认黑白字总能清楚。渐变检查各段、纹样检查最细线和导出压缩后的实际尺寸。灰度预览帮助发现层级问题，但不替代真实色彩与多种色觉检查。

## 5. 具体例子：春季文化展，粉色背景与浅绿小字

**综合示例设定：** 公共文化展，希望春意、温和，需手机传播和印刷；用户喜欢粉底、浅绿小字并希望传统色名。先保留粉绿方向，让浅绿承担枝叶图形与局部色面，关键信息改用深绿。若浅绿小字不可改色，可将其置于合适的深底区域并实测，或保留为装饰且另有完整可读信息。

以下为新设定的 **sRGB候选**，不是传统色谱的权威映射：

| 角色／项目别名 | HEX | 应用约束 |
| --- | --- | --- |
| 背景／春粉 | `#F4E4E7` | 大面积浅背景；不叠浅绿关键信息 |
| 文字与主体线条／深叶绿 | `#24473E` | 标题、时间地点、说明；也可作浅字的深底 |
| 辅助图形／芽绿 | `#B9CDBA` | 枝叶、色块；不作粉底小正文 |
| 留白／暖纸白 | `#FAF7F0` | 信息区域、深底文字候选；不意味着实物纸白固定 |

先用粉底覆盖主要背景、浅绿集中在植物图形，深绿组织阅读。面积根据展品照片、标题长度和入口试排调整，不锁定比例。已有馆徽／展品图加入后重新判断综合色。

**现代补充的计算例：** 按sRGB相对亮度公式计算，不透明纯色之间深叶绿／春粉约8.36:1，芽绿／春粉约1.37:1，暖纸白／深叶绿约9.59:1。这是本例计算结果；没有字体、半透明、图片、显示条件或印刷校样的合格保证。若项目约定正文目标为4.5:1，则前者满足这一数值目标，浅绿组合不满足；实际采用何种无障碍标准和适用阈值，应查其官方要求并记录。仍需按最终字号、字重和实机检查。

传统色名要求单独处理：有指定中国传统色资料时，记录可靠来源、版本、条目和取值条件，再选色、注明数字化近似。上述“春粉、深叶绿、芽绿、暖纸白”只作为本项目意象别名。尚未考证时先交可用数字方案和待核名称，不编造“古代唯一HEX”，不将日本色名表当中国色谱。若交付要求必须有确证的传统名称，名称考证完成前这一项保持待定。

## 6. 分媒介验收与记录

屏幕显示、实际油墨、纸张与观察条件分别记录；不能把两种屏幕颜色直接当成两种印刷油墨。

| 检查对象 | 实际动作与通过条件 | 留下的证据 |
| --- | --- | --- |
| 整体层级 | 同内容全尺寸和缩略预览；第一焦点符合约定，背景不掩盖主要信息 | 应用图、问题位置与改法 |
| 文字与图形 | 用真实文案、字号、字重测所有必要组合；渐变／图像查最不利区域；满足项目适用目标，边界可辨 | 颜色对、测量方法／阈值／结果、最终尺寸截图 |
| 分类与状态 | 灰度与色觉模拟辅助检查，并用标签、形状等独立线索识别；模拟不能代表所有人的体验 | 关键状态／图例的实际应用 |
| 手机传播 | 在实际目标尺寸查看导出物，检查压缩、浅色细线、文字与二维码；涉及网页时做真实浏览器检查 | 实机或浏览器截图、扫码结果 |
| 印刷 | 与供应商确认纸、油墨、工艺、ICC／输出条件；软打样提示风险，再看带实尺寸文字和大色面的实物校样 | 输出条件、校样照片／编号、签样或修改记录 |

HEX、RGB和CMYK即使同时列出，也要说明是否为独立参考值、在何配置下转换、是否打样。不能凭一个通用换算公式保证一样。高饱和屏幕色、金属／荧光、透明与叠印、纸张本色尤其要单独确认。两种屏幕颜色不等于两种实际油墨；双色印刷还须确认分色、网点和叠印，纸色可能成为第三个可见组成部分。专业制版参数由供应商核准。

最终按“已计算／已查看／已打样／待验证”报告。仅提出上述春展方案时，应写：已形成颜色角色和数值候选；可报告已做的纯色计算；真实物料、传统色名考证及印刷一致性均尚待对应验证。

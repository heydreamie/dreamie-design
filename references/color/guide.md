# 配色设计

先确定颜色要帮助观众看到什么、理解什么，再选择颜色关系。交付颜色的用途、面积、搭配和验证条件，不能只交色名与HEX列表。

## 使用边界与参考

- 具体步骤、纠错和完整例子见 [methods.md](methods.md)；书籍定位、阅读覆盖及证据限制见 [sources.md](sources.md)。
- 中文网站或界面同时使用 项目已有的中文 UI 工作流（如可用），由它管理字体、组件、状态、交互和真实浏览器验收。本专题补充颜色决策，不取代UI规范。静态图文的容量与版式问题可衔接 [版式专题](../layout/guide.md)。
- 书中的色彩联想是候选方向，须结合品牌、内容、文化语境和实际观众。不能按性别、年龄机械指定颜色，或把配色宣称为医疗、销量、情绪控制的保证。

## 执行步骤

1. **建立任务基准。** 读取现有品牌规范、必保留颜色、真实照片与文案。明确用途、受众、第一视觉焦点和载体；屏幕、普通四色印刷、专色或实体材料分别记录。资料不足时注明假设并给可调整方案，不虚构官方色值。
2. **选统一路径。** 单一大色面可用主色带动；多个近等面积色块可用共同色调统一。明确采用相近色相、相近明度与彩度、互补对比或照片综合色等关系，解释它怎样服务主题。必要时用同一内容比较两个有理由的方向，不堆无差别备选。
3. **分配角色再给数值。** 至少区分背景、主体／品牌、文字、强调及必要的分类／状态色。角色可含多个颜色；不把“三色”当成最多三个HEX，也不强制统一面积比例。给出每色的色彩空间、数值、位置、预计面积或强弱关系、允许搭配和禁用组合。
4. **检查关系与真实内容。** 把照片、纹样、渐变、留白及材料本色计入整体。检查主次、大小面积变化、文字与背景、细线和相邻色边界。色相差大不代表易读；调整明暗、彩度、面积或插入分隔，而非一味加鲜艳色。
5. **分别验证媒介。** 屏幕用最终尺寸、真实字重与导出图／页面检查；按项目适用的现代无障碍规则测具体前景背景组合，记录规则、阈值和结果。印刷记录纸张、油墨、输出配置和工艺，软打样后以实物校样确认。HEX确定的是约定空间内的数字值，不能保证各屏幕或印刷呈现完全相同。

## 交付与验收

输出包括：设计依据；带用途的色板表；一段实际内容的应用规则；冲突改法；按媒介列出的验收动作、通过条件和当前证据。色名若来自文献，写明来源版本与转换条件；自拟名字明确标为项目别名。不要把参考书中的日式色名冒充中国传统色名。

只给方案时写“待应用与验证”；实际测量才能报告数值，实际查看或打样才能报告对应验收。数值对比度通过仍需检查字号、字重、图像变化与阅读路径。颜色承担分类或状态时，同时提供文字、形状、纹理或位置线索。

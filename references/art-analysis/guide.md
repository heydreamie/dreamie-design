# 艺术作品的设计分析与迁移

先看作品中的关系，再解释它如何起作用，最后把有用的方法转换到新任务。北斋是学习入口，不是固定的“蓝色巨浪”模板。

## 观察与解释

1. 确定作品、版本和任务。可取得用户图或可靠图像时先实际查看整体及相关细节；可靠图像与解释的核验要求见 [sources.md](sources.md)。裁切图、分析叠线图与完整原作须区别。没有图像时可给知识性概述或待验证假设，同时继续获取可用图；不能据作品名编造人物表情、精确比例或色值。
2. 读 [方法与应用](methods.md)，选与本次问题相关的观察维度：构图与视点、色彩关系、图形/纹样、取舍与景别、人物动作、几何、线条。画面没出现的维度无需凑齐。
3. 按“位置及可见证据 → 关系及可能效果”说明判断。动作、衣褶、朝向与面部表情分别观察；细小、遮挡或背面的人物不推定完整神态。心理、身份、象征、时代背景和创作意图分别说明证据来源与解释限度。
4. 用户要精确数据时先定义测量对象、完整画面边界和方法。相对位置可用归一化坐标；色值须记录数字图来源与取样区域。扫描颜色、纸张老化或套印差异不能直接等同原始颜料。三分线、黄金比例或几何辅助线是解释工具，吻合不自动证明作者按该公式创作。

## 迁移到具体设计

先确定受众、主题、媒介、信息优先级和品牌约束，再交付迁移表：**原作关系 → 新任务中的对应关系 → 具体改动 → 验收动作**。优先迁移视线引导、大小关系、虚实、色彩角色、重复节奏、线条与材质；图像题材依据任务决定。

用户明确要临摹、复刻或保留某个题材时尊重该范围，说明采用哪一版本及哪些细节可确认；普通风格迁移不自动复用原作全部物象。原作、现代解说与数字图像的使用条件分别核对，对外展示标明参考或重绘状态。

## 交付契约

- 分析：作品/图像范围、关键观察、解释与来源、不确定点；有测量则附边界与方法。
- 设计：新任务目标、关系迁移表、可制作的构图/配色/线条规格及资产说明。
- 验收：实际查看整体、最终展示尺寸和相关细节；能否先认出主题、读到必要信息、完成行动。只交方案时列待验证项；实际制作后保留预览或截图，按观察到的问题复查。不得用“像北斋”代替可检验的标准。

执行以本次授权为准。本专题不要求固定轮次、固定风格或额外审批；分析不扩大为未经授权的外部发布。

# 读画、解释与设计迁移

## 内容地图

第1节解决证据与测量，第2节提供七类方法入口，第3节给迁移方式，第4节为完整应用，第5节是验收与常见偏差。

本文件整理读画与迁移方法。可见观察、形式解释、历史证据和设计提议分别标记；图像与事实核验见 [sources.md](sources.md)。现代设计或摄影类比不自动等于作者本人声明或艺术史结论。

## 1. 从观察到解释

**编写者综合。** 分清以下四种陈述，能让分析准确而仍有深度：

| 陈述类型 | 例子 | 如何支撑 |
|---|---|---|
| 图像观察 | 前景大弧线包围较小的远景山峰；人物多为俯身姿态 | 指明位置，实际看图；需要时查看细节 |
| 形式解释 | 大小与动静关系使远处焦点更稳定，近处更有压力 | 指向可见关系，用“形成/可能增强”等符合证据的话 |
| 研究解读 | 将某种视角比作长焦，或把人物互动读为幽默 | 记录可靠来源与证据性质；形式类比本身不能证明历史事实 |
| 新设计提议 | 把包围性弧线改成展开的书页，引向活动标题 | 说明是新的设计决定，以新任务验收 |

不要把姿态替换成无法看见的表情。某人弯腰、抓物、望向侧面，可以支持动作分析；“他害怕”“她责备孩子”“作者童年回忆”需要额外证据，或明确是可能读法。人物故事的解释可用于提出观察问题，不作为每个人内心的确定答案。

有两张不同版本时，先比较裁切、纸色、线条、色层和保存状态，再讨论形式。要做精确构图测量，应取得边界完整、没有透视变形的目标版本，标明是否包含题签与落款；裁切或叠线分析图不能代替完整原作。

**工具补充：测量契约。**

- 位置：以画面左上为原点，横向用 `x/W`、纵向用 `y/H`，注明坐标与误差范围；“约在右侧三分线附近”与“测得x/W=…”不同。
- 面积：说明是外接框占比、轮廓分割面积还是某颜色像素占比，不能混称“构图比例”。
- 色彩：记录图像版本、色彩空间、采样区域和方法；给出的数字是该数字图像的采样值。纸底、白浪与高光不要不加区分地都称为纯白。
- 作者意图：辅助线与物体相合，只能支持一种构图读法。密集添加辅助线总能产生若干交点，不能以此证明存在唯一公式。

## 2. 七类方法入口

### 构图：注意力如何移动

**编写者综合。** 先说主体与视点，再看主线、重心、大小、间隙和出画关系。三分和对角不是必须同时套用的网格；居中、对称或水平中分也可服务平静与稳定。圆弧既可能压迫，也可能包容，要看朝向、闭合程度、尺度与内部对象。

可迁移的例子：把斜向方材引导视线的方法用在活动流程的视觉连接；将遮挡透见改成书架缝隙里出现主角；让近处大物与远处小物形成探索路径。新任务若强调安全与轻松，应调整压迫性和不稳定感。

### 色彩：谁是主角，谁在衬托

**编写者综合。** 先分色彩角色：背景、主体、连接、强调和文字；再看明暗、冷暖、彩度、面积与相邻关系。迁移的是关系，不必复制同一组色相。品牌色已定时，可保留“低彩背景衬高对比主色”这一关系，重新试排。限制色数是控制复杂度的方法之一，不是所有设计都只能三色。

题材颜色不作证明：画面蓝色不证明颜料成分；绿色屋面不证明环保；近似配色不证明影响关系。纸张黄化或不同印次可能改变我们看到的色调。

### 意匠：从单位元素到系统

**编写者综合。** 做纹样先确定单位、变换规则、连接位置、节奏与负形，再检查平铺边界，不能只复制漂亮的一格。做品牌图形可学习识别尺度与简化方法，已有家徽/商标不自动变成新品牌标志。做信息图先让动作和结构可理解，再追求装饰。应用到实物时检验图形在弯曲、裁切、接缝和不同尺度上的变化。

### 分析与判断：选择什么，省去什么

**编写者综合。** 长焦、广角等可以作为观看关系的现代类比，不能据版画推算实际镜头焦距或证明画师使用摄影器材。任务若只需一个明确焦点，删去无关信息；任务要说明全过程，则安排层次与连接。宏观构图和微观观察配合，不能因为构图有趣就忽略手、工具、关节、物种或产品结构。

### 四季与人：用动作传递生活

**编写者综合。** 为人物设计一个与事件有关的动作，胜过给所有人同一张笑脸。儿童活动可用递书、翻页、寻找图案等关系表现参与；画里看不清眼睛，也能分析身体朝向。不要将地域习俗、阶层或人物性别刻板化，更不要把对心理的推测写成确定史实。

### 几何：简单形如何连接复杂内容

**编写者综合。** 从题材中发现可用的几何结构：书脊矩形、翻页弧线、灯罩圆面、山体三角等。选择一种主关系再加变化，不为“数学美”把自然对象硬切成几何块。几何解释也不能证明桥梁真实承载或物理结构可行。

### 线条：形态、材质与情绪

**编写者综合。** 看线的粗细、节奏、方向、连续/断裂、密度、边缘和点线关系。线密度可以表现明暗和材质，但需要留出呼吸空间；轮廓决定识别时，避免纹理线把形状吞掉。笔触外观、底稿、雕刻和印刷分工须区分，不把每一处印刷痕迹都归为作者直接下笔。

## 3. 关系迁移表

**编写者综合。** 从原作选少量与目标相关的机制，逐项写到目标对象和操作上：

| 原作关系 | 新任务对应 | 具体操作 | 检查 |
|---|---|---|---|
| 大的近景包围小的远景 | 主视觉包围活动焦点 | 调弧线开口，给标题留完整区域 | 焦点清楚且无字被切割 |
| 重复元素有大小/疏密变化 | 系列活动或步骤 | 同类图形共享骨架，间隔控制节奏 | 既能辨类，又不会误读数量/顺序 |
| 低彩度背景衬主色 | 品牌色成为识别点 | 先降低背景竞争，再分配强调面积 | 缩略图先看到正确主题 |
| 圆形框景与远处呼应 | 阅读窗口、产品观察窗 | 保留框景关系，替换为与任务相关对象 | 框景有意义，主体不被装饰遮挡 |
| 动作与环境共同显示风 | 页面/书签/人物动作显示探索 | 选一条共同运动方向，并保留稳定支点 | 动势连贯，读字和操作不受干扰 |
| 密线与疏线形成材质差别 | 图形层次与文字邻区 | 纹理集中在主视觉，文字区减密 | 最终尺寸细线不糊成块 |

用户明确要求保留原画波浪或直接临摹时，可保留该物象，并结合主题调整其位置与规模；表格仍用于说明新信息怎样进入画面。不要凭技能预设擅自更换用户已确认的题材。

## 4. 应用：儿童读书节海报

**编写者综合示例。** 假设面向6—12岁儿童及家长，任务是“被阅读探索吸引→读到活动名、时间地点→报名”。用户希望借鉴《神奈川冲浪里》的力量感，尚未提供完整目标图。

**分析范围。** 先取得可靠的完整参考图再建立构图观察；正式精确测量还须明确图像边界与版本。以参考图中可确认的关系为准，例如：大弧形巨浪与小型远山的尺度差，舟和水线的重复，深蓝、浅暖背景与白浪的对比；不能据此逐人解释面部情绪，也不能将分析叠线图当作北斋创作公式的证明。

**迁移方案。** 原画的大弧线关系转成展开书页形成的上扬弧形，稳定的小焦点改为远处灯塔或阅读小屋；数个孩子分别翻书、递书、指向探索对象，身体动作清楚而不堆细小表情。主视觉下半部较密，上方留连续标题区；曲线把视线引向标题，再下行到时间地点与报名区。沿用深浅对比和暖色陪衬关系，具体色相由活动品牌决定。若用户明确要求原波浪，则保留可确认的浪形，以书舟与人物活动建立读书主题，降低它对标题和二维码的遮挡；不擅自把波浪改成书页。

**可执行规格。** 先画黑白线框标明主视觉、标题、时间地点、活动内容和报名区；决定一个主要弧线方向、一个稳定焦点与一种重复单位。局部线密度在主视觉中变化，文字和二维码邻区保持清楚。中文标题使用实际排版图层，报名二维码使用真实可扫码资产。尺寸、字级和净空按实际媒介设置，别把原作横幅直接裁成竖版后称为迁移完成。

**验收契约。** 缩略图能识别“儿童阅读活动”；打开成片先见主题再读必要信息；人物动作能辨且无肢体连接错误；主线不会把视线引出画面或切断标题；二维码与文字均有清楚的空间；在实际展示尺寸检查线条不糊、颜色不吞字，最终导出可扫码。若仅交方案，以上均列为待验证；实际制作时看成片再记录通过或具体问题。

本例给出的是设计提议，不是原画内容，也不是已经制作完成的海报。受众、品牌、原画版本或媒介变化后应重新判断，不强制复用本例对象、颜色和布局。

## 5. 评审与修正

使用“位置与证据→问题与影响→改法→复查条件”的方式给意见：例如“报名区被密集浪线穿过，降低二维码与说明的辨识；将浪线止于主视觉边界，保留连续净空；用最终导出文件扫码并在手机正常尺度复看。”

| 偏差 | 修正方向 |
|---|---|
| 没有目标图仍断言每人表情、精确坐标或HEX | 先取得图像；在此之前只说明可支持的概述和测量计划 |
| 辅助线越画越多，称作唯一秘密公式 | 选能解释主要关系的少量线，列为分析读法而非作者自证 |
| 只有“北斋蓝+波浪”几个标签 | 回到受众与目标，选择构图、色彩角色、线条或节奏中的适用机制 |
| 为迁移而排斥用户明确要求的物象 | 尊重已确认题材，在范围内调整关系和新信息的空间 |
| 宣称扫描色就是原作颜料或历史精确色 | 标明数字图取样条件，将颜料/年代考证另行处理 |
| 形式分析华丽但活动信息读不到 | 恢复阅读与行动顺序，减少装饰竞争，复核实际展示尺寸 |

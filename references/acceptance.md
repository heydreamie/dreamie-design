# 共同交付与验收

按本次任务选择相关检查，不为小修复启动整套全站评审。具体媒介的方法以对应专题为主。

## 设计依据与证据

先说明受众、核心阅读/操作路径、内容优先级、媒介、保留项及采用方向。评审项写成：

**位置与证据 → 问题及影响 → 具体改法与取舍 → 验收动作与通过条件。**

证据区分已观察、用户提供但未复现、源码风险、计算结果和待验证。未取得图像时不声称看到了细节；未执行渲染时不声称成品视觉通过。规则扫描和构建成功只证明相应技术检查。

## 中文文字与图像

- 本次品牌与字体要求优先。未指定时可先试可读性良好的无衬线中文字体；实际检查汉字字形、缺字回退、字重、标点和中英混排，不只检查字体名称列表。
- 字号、行高、行宽与段距联动；长标题和最长真实文案需试排。不能将日文Q、印刷pt、CSS像素和导出图片像素混为同一单位。
- 图片等比处理并检查主体裁切、清晰度和实际用途；准确文字、标识、二维码和产品标签须逐项核对。图像中的“矢量外观”不等于实际可编辑矢量。

## 按媒介验证

| 媒介 | 实际动作与证据 |
|---|---|
| 海报、图片与书册 | 缩略看主次，最终尺寸看文字，放大看细节；保存代表页预览，检查溢出、遮挡、图片比例与连续页面节奏 |
| 中文网页/UI | 在真实浏览器检查相关桌面与手机尺寸、实际字体与长内容、键盘焦点、核心触屏路径和加载/空/错误状态；保留关键截图 |
| 色彩 | 使用真实内容、相邻色面与图片；记录实际颜色空间、测量目标和条件。数值通过仍需看字号、材质和整体阅读 |
| 连续纹样/矢量 | 查看对应边和角、3×3与较大阵列、最小使用尺寸、实际导出；器物另查展开、接缝、折边与曲面 |
| 印刷/实物 | 确认目标纸张、油墨、工艺、输出条件及供应方指标；实际尺寸校样、扫码、材料打样；未打样就列为待验证 |
| AI生成图像 | 实际生成后核对主体、角色/产品一致性、文字标识、细节失真、画幅裁切与实际格式；仅交提示词则明确尚未生成 |

按一批问题修正后复查，仍有缺陷再定向处理。不为了固定轮数重复截图，也不把概念方案说成已完成生产。

## 输出的状态

结尾列实际文件或规格、执行过的检查、证据位置、剩余缺陷和待补条件。概念稿、已计算、已渲染、已打样分别说明。对外发布、推送与生产按当前用户授权执行；技能方法不扩大授权。

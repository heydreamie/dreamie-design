# 方法、条件与应用

## 使用地图

- 风格选择与拆解：第1、2节。
- 提示词与平台适配：第3、4节。
- 产品海报的完整应用：第5节。
- 生成后的检查与改图：第6节。

风格选择、执行设置与实际输出分别记录；素材与工具核验要求见 [sources.md](sources.md)。

## 1. 先决定任务需要什么风格

同一描述在不同软件或重复生成时可能得到不同图像。风格家族用于检索，可互相交叉，不应当作互斥的艺术史分类。

**编写者综合。** 先用一句话定义结果，例如“让年轻用户先认出茶罐，再感到清爽安静，最后读到上新日期”。据此判断图像承担的是主体辨识、情绪营造、叙事还是空间展示。选一个承担主要任务的风格骨架；如需混合，明确第二种语言负责哪个局部。品牌指定方向时直接在该方向内细化，无需强制增加方案或追问。

| 任务/情绪 | 可考虑的方向与可见控制项 | 使用条件与代价 |
|---|---|---|
| 温柔、轻盈的生活题材 | 水彩：透明叠色、软边渗化、留纸白；治愈插画：简化角色、柔和关系、安静场景 | 产品轮廓和文字附近保持清楚；“温柔”不要求一律粉色 |
| 小尺寸快速识别 | 扁平/描边：简化轮廓、有限色块、明确线粗；粗描边插画可加入断线、填色偏移 | 以实际可见的造型、线粗和边缘描述，不依赖含义含混的流派缩写 |
| 儿童叙事 | 绘本：清晰动作、角色关系、年龄适配、重复叙事线索 | “鲜艳可爱”不足以讲故事；多页先建立角色特征表 |
| 现代国风 | 传统题材/器物/文化线索，加现代构图、色彩与线条；可取水墨虚实或工笔细节 | 选择与产品有关的传统依据；不默认舞狮、祥云、朱砂红或古装 |
| 强烈、动态的表达 | 表现主义的形变与非自然色；构成主义的几何结构与方向性；涂鸦的喷绘/手写痕迹 | 商品精确外形应保留在真实产品图层，避免一并变形 |
| 秩序、信息清楚 | 瑞士风格的网格与层级；极简的负空间与有限视觉焦点 | 排版需后期实际完成，生成的伪文字不能承担信息 |
| 梦境、观念隐喻 | 超现实的尺度变化、异物并置、非现实关系；概念摄影的符号 | 用一个明确视觉隐喻服务主题，减少互相争夺的奇观 |
| 材质或产品展示 | 明确粗糙度、反射、透光与光源；玻璃外观可用半透明、磨砂、边缘高光 | 光泽与背景须协调；材质效果不证明真实材料性能 |
| 摄影感 | 视点、焦段感、景深、自然/棚灯、灰度、抓拍感或布景感 | 生成图是摄影外观，不是事件、物种或地点的实拍证据 |
| 家居/建筑概念 | 体块、空间连通、材料、采光、装饰密度、视角与环境 | 固定门窗、尺寸、动线时以真实图纸/模型约束；概念图不证明结构可行、节能或环保认证 |

上表是选择起点，不是适用场景的唯一答案。其他绘画语言可按第2节拆解，例如油画侧重笔触、体积与光色，版画外观侧重轮廓、线密度、色块与套色感，抽象语言侧重节奏、形状关系和情绪。避免仅报一个艺术家名字便当作完成风格设计。

## 2. 风格卡：把名称变成画面关系

把风格拆成可见特征：水墨的虚实与留白，水彩的透明叠色、纸白与渗化，插画的轮廓、色块与空间，摄影外观的视点、光影与景深。

**编写者综合。** 将参考图或风格目标写入以下表格，保留与本次结果有关的行。没有参考图时写作设计决定；观察图片时写作可见证据，不把自己的提议说成原图固有比例。

| 变量 | 可执行的描述 | 需要检查的冲突 |
|---|---|---|
| 主体与动作 | 一只直立的茶罐；一名孩子双手打开书本 | 数量、左右、姿态或产品外形矛盾 |
| 构图与空间 | 主体在下半区；右上留连续清洁区域；前中远景 | 同时要求正视与鸟瞰、满版细节与大面积留白 |
| 造型与线条 | 硬边几何；圆角粗描边；细线工笔；夸张比例 | 轮廓简化影响品牌/物种辨识；线粗不统一 |
| 色彩关系 | 低彩度背景、较深主体、少量暖色焦点 | 把配色名称堆成彩虹；品牌色偏移；文字缺对比 |
| 材质与笔触 | 半透明水彩、局部软边、细纸纹；哑光陶瓷 | 同一区域同时要求纯平无阴影与高反射写实 |
| 光影 | 左上柔光；浅而有方向的投影；边缘透光 | 多组互斥光源；反射不合场景；主体被高光吞没 |
| 情绪与叙事 | 平静、专注；动作朝向信息区域 | “平静”与高密度爆裂动效抵触；装饰喧宾夺主 |

可以将某个变量做成小样对比，如仅更改“硬边/软边”，而保留主体、画幅和色彩关系。这个办法比同时换模型、换构图、加风格词更易判断改动的实际作用。

## 3. 提示词组织

**编写者综合。** 使用这条语义顺序作为起点，根据工具输入格式缩写或扩写：

> 画面用途与主体 → 数量/动作/关系 → 构图与文字留区 → 造型和线条 → 色彩关系 → 材质与光影 → 氛围 → 不可变约束。

一条优秀提示词应能对应到实际图像，避免把“8K、获奖、最佳、某渲染器”当作画质或文件规格的保证。名词不能替代视觉决定。负面约束是否支持、怎样输入，由工具决定；先把正向意图写清，再表达必要限制。

按本次任务重写提示词，清理错译、重复和互相冲突的要求，不机械整段复制现成例词。需要真正SVG、准确文字、指定ICC或可编辑图层时，在输出和制作流程实现，不靠提示词声称已完成。

## 4. 语义与执行设置分开

**工具补充；不构成对任何最新版软件的事实说明。**

| 记录项 | 应记录什么 |
|---|---|
| 语义提示词 | 本次实际使用的描述，包含参考图及其用途 |
| 执行环境 | 平台、模型/检查点、版本或工具公开的模型标识；无法取得则注明 |
| 专用设置 | 仅记录该环境实际支持并使用的画幅、尺寸、参考强度等；工具提供采样器、步数、种子时一并记录 |
| 来源与状态 | 参数依据来自工具帮助/官方文档及日期；“文档支持”和“已实际生成”分别写明 |
| 输出 | 实际像素、文件格式、编辑/放大/合成步骤和仍需完成的项 |

不同平台的命令尾缀、参考机制与采样设置不能直接互搬。用户需要可运行方案时，核对当前环境并验证最小样例；工具不可用时交付语义描述与待适配项，继续完成不依赖运行的设计工作。

参考图可以用于构图、身份、产品外形或材质；明确所需约束，避免一个“参考强度”同时承担所有任务。模型未能维持产品/角色时，用原图合成、局部编辑或真实资产替换，按当前工具能力选择。

## 5. 应用：现代国风茶产品海报

**应用示例，参数按真实项目调整。** 假设受众为关注生活品质的年轻人，竖版用于社交媒体；产品为品牌提供的真实茶罐，标题“春山新绿”，品牌logo由用户提供。若实际产品或品牌不同，应重定方向。

**方向。** 用山水的虚实和远近层次表达春茶的轻盈，用现代留白布局保证读字；茶罐保留摄影材质，山水只承担环境。备选方向为细线茶枝与有限平涂色，适合更强调图形识别的品牌。选择依据是产品与受众，不是“国风必用青绿”。

**风格卡。** 下半区放真实茶罐；山形从两侧低处进入，不穿过标签；远山低对比、近处少量茶叶细线；纸白为背景，灰绿衬景，产品品牌色为焦点；光线柔和，茶罐接地；标题位于上方连续留区，logo置于品牌规定位置与净空。这里的位置是本次布局提议，实际按品牌规范调整。

**背景语义提示词。**

> 为春茶产品海报制作竖版背景。背景为浅纸色，远处山形用灰绿淡墨形成疏密层次，下部两侧以少量细线茶枝收边。中央下部留出清楚、平稳的产品摆放区域，上部保留完整安静的标题区域。山形边缘虚实相间，细微纸纹，柔和自然光，清新、从容。画面只包含环境和少量茶枝，产品、标题及品牌标志由后期图层加入。

**制作。** 先生成背景；把真实茶罐图合成在预留区域，匹配投影与色温；以可编辑文字输入“春山新绿”，放置官方logo。若用户明确希望直接生成含字版本，可先试，再逐字检查；错误局部替换，不必整图重做。没有官方logo时保留净空并标明待素材，不伪造品牌标志。

**工具设置。** 按实际工具填写模型、输出尺寸、参考素材和所用设置；本示例不给未验证的平台参数。需要多版本比较时固定布局和产品，分别比较墨色的疏密或线条的粗细。

**验收契约。** 产品型号与实际素材一致；标签不被景物遮挡；标题四字逐字正确且小屏可读；logo形状、比例和净空符合规范；主视觉→标题→辅助信息的顺序清晰；没有多余伪文字、重复产品或断裂枝叶；输出达到实际发布渠道要求。未拿到产品/logo素材或尚未生成时，报告这些项待验证，不能报告成片可发。

## 6. 观察—定位—修改—复查

**编写者综合。** 生成前写出本轮最重要的通过条件，生成后按证据处理：

| 观察到的问题 | 首选修改 | 复查 |
|---|---|---|
| 主体被背景淹没 | 降低背景细节/对比或调整主体位置 | 缩略图中能否先看到主体 |
| “国风”只剩泛化装饰 | 选一个与题材有关的文化线索，说明造型/构图关系 | 去掉说明文字后能否看出与产品的联系 |
| 风格混乱 | 确定主语言，把次要风格限定在具体层/区域 | 轮廓、材质、光源是否协调 |
| 中文或标志错误 | 实际字体排版、官方资产替换或局部编辑 | 100%视图逐字逐形，最终展示尺寸复看 |
| 产品/角色变化 | 约束参考、局部修正、真实资产合成 | 对照原素材，系列图并排检查 |
| 只有外观，无可用交付格式 | 继续制作实际矢量、排版或生产文件 | 在目标应用打开并检查内容可编辑性 |

检查既包含整体构图与缩略图，也包含100%细节和最终展示尺寸。实际生成或发布仍按本次授权范围执行；风格设计不自动授权外部发布。无法运行时交付可继续制作的方案，并把未运行与未验收写清。

# 图文版式设计

先决定读者要看到、理解和完成什么，再把信息作用转换成空间、层级和阅读路径。网格、黄金比例、居中或留白都是可选手段，内容与媒介决定其使用条件。

## 范围与衔接

适用于静态图文及其跨媒介转译。中文网站、作品集或工作台同时使用 项目已有的中文 UI 工作流（如可用） 完成界面预检与交互验收；本专题补充版面结构、图文关系和系列节奏，不代替响应式、语义、键盘或触屏检查。已有品牌、用户指定风格及已确认方向优先。

方案与评审读 [methods.md](methods.md)；需要核对素材、单位与验证边界时读 [sources.md](sources.md)。

## 工作方法

1. **建立信息清单。** 使用真实标题、正文、图片和操作入口，标出吸引注意、解释、比较、行动及附属信息，给出保留项和浏览顺序。缺少文案时按假设估算最长内容，并标明未试排。普通任务合理默认继续，不因缺一份设计简报而停工。
2. **同时确定媒介。** 记录成品尺寸、观看距离、阅读姿态、输出方式；多端任务从一开始分别安排版式，明确共享的识别元素和必须重排的内容。印刷查裁切、装订、纸张与工艺；屏幕查实际显示宽度和文字放大。
3. **把结构写成可执行规格。** 选择单栏、栏网格、模块网格或受控自由布局，并说明理由。给出边距、栏宽、栏距、对齐锚点、文字层级、图像尺度、裁切及入口位置。数值标为试排起点；不要用空泛风格词代替规格。方向未定时可用相同内容比较少量实质不同的草图；已明确则直接推进。
4. **先建立主次，再检查细节。** 缩小看第一焦点与信息组块；正常尺寸看中文断行、标点、字形、间距、图注关联和图片细节。系列材料先设稳定的信息类型，再用密度、尺度和留白调节节奏。网格允许跨栏，跨栏要服务内容。
5. **渲染、查看、复查。** 用户要方案时交付规格及验收计划；已授权制作时实际渲染并检查代表成品。手机转发图按实际聊天预览及打开后分别查看；印刷按实尺寸打样并核对生产要求；二维码用最终导出和打印样扫码。保留关键截图或样张记录。

## 输出契约

- **设计依据：** 受众、核心路径、信息优先级、媒介与保留项。
- **版式规格：** 内容顺序、网格与对齐、层级、间距、图像处理、入口；多端给各自规格和重排规则。
- **验收记录：** 位置与证据 → 问题及影响 → 具体改法及取舍 → 验收动作与通过条件。区分已观察、数值起点、源码风险、待验证。

不要将“构建成功”“套用了网格”或“规则扫描通过”写成视觉验收通过。未实际查看或打样时，明确交付的是方案和待验证项。

## 常见误用

| 现象 | 调整方向 |
| --- | --- |
| 所有文字同大或同时抢眼 | 先按作用归组，选第一入口，再减少竞争强调 |
| 内容塞不下就压扁字或无限缩字号 | 先调整信息组织、空间分配、重排或页数，核对阅读条件 |
| 图好看但与内容无关 | 明确其解释、证据或情绪作用；无合适素材时允许纯文字 |
| 纸媒整页等比缩成手机图 | 保留识别元素，按实际显示尺寸重新分配层级与阅读顺序 |

# 版式决策与执行

本文整理信息层级、网格、图文关系与跨媒介验收的执行方法。素材、单位和验证边界见 [sources.md](sources.md)。

## 1. 从信息作用分配空间

文字大小、重量、位置和间距共同形成层级；图注应与对应图像保持明确关系。先整理元素数量与作用，预留必要信息，再放大最希望读者先看到的内容。纯文字也能构成完整设计。

`[综合]` 做一张任务表，避免将“字号大小”当成唯一层级手段：

| 信息作用 | 可执行决定 | 检查 |
| --- | --- | --- |
| 吸引注意 | 一个主要标题、主图或关键事实作为入口 | 缩略图中先看到的是否符合目的 |
| 帮助理解 | 副标题、正文、图注与主元素成组 | 能否明确说出每段解释哪一项 |
| 比较与选择 | 同类内容共享字段、对齐和视觉尺度 | 能否快速比较，不靠反复来回寻找 |
| 完成行动 | 时间地点、报名入口、截止条件集中 | 是否能从理解自然进入行动 |
| 查阅附属信息 | 页码、来源、联系人等稳定定位 | 可查找且不压过核心内容 |

缺空间时先判断：冗余可精简吗，内容可分组吗，栏宽可调整吗，是否需要增页或另设详情？保持必要内容；删改原文超出授权时给出具体建议。不要先用机械压缩字形解决容量。

## 2. 选择结构而非套固定版式

栏网格强调纵向秩序，模块网格便于图文组合；基线网格组织行的节奏；无网格设计仍需内部关系。一个网格可通过合并单元、跨栏、改变图片尺度生成多种版面。

| 条件 | 结构起点 | 必须写清的变量 |
| --- | --- | --- |
| 连续阅读、单一叙事 | 单栏或少量正文栏 | 行宽、字号、行高、段距、锚点 |
| 多种并列信息、重复条目 | 栏网格或模块网格 | 内容宽度、栏数、栏距、跨栏规则 |
| 主图承载主题、文字辅助 | 主图与文字区域协同 | 主体保留区、裁切焦点、图注位置 |
| 强表达海报、非线性观看 | 受控自由布局 | 主要入口、视觉连接、必要信息稳定区 |

`[综合]` 网格可计算但须试排：版心宽度 `W = 成品宽度 − 左右边距`；等宽栏 `c = (W − (n−1)g)/n`。例如版心宽270mm、3栏、栏距6mm，则每栏86mm。这是几何关系，不证明文字一定读得清。正文可能跨两栏，图片可占整栏或多栏；不要把所有对象都压进相同小格。

黄金比例、古典页边距可用于草图比较，但不存在适合所有主题和成品的最佳比例。西文“每行60字符”、连字符和斜体案例不能直接成为中文的标准行宽或层级规则。

## 3. 中文文字与图像一起检验

文字框整齐不等于字面间隔自然。先选适合内容的字形，再联动调字号、行宽、行距与段距；正文、标题和图注有不同要求。

`[现代补充]` 中文字体依据本次品牌与用户要求选择；未指定时优先试清晰的无衬线字体；检查实际字形、缺字回退、标点禁则、中英数字基线、连续长名称及断行。短标题可以居中；长段正文先试统一左侧起点，需要两端对齐时检查字间是否被拉散。网页允许内容自然增高并验证文字放大，不以印刷定高文本框约束可变内容。

日文排字的 `1级(Q)=0.25mm`；DTP常用 `1pt≈0.3528mm`。不要把14级抄作14pt或14px。印刷 pt、屏幕 CSS px、导出图片像素分别说明；手机图的30像素源字在缩到原宽三分之一时只相当于10像素显示高度，不能只检查源图100%。

图片须决定用途和观看尺度。保留背景可传气氛，抠图可聚焦对象，组图可说明多个角度；裁切会改变意义，面孔、证据性细节不要落入订口或被裁去；图与文字应有关联。

`[综合]` 为主图写出“主体、保留区域、裁切方式、最小可辨细节、与文字关系”。等比缩放，不因适配画框任意拉伸人物。照片叠字先找视觉简单区域，必要时统一处理整组文字背景；渐变、遮罩、实底文字区均按成品可读性与主题选用，不照搬某一种偏好。

## 4. 系列与跨媒介

同类内容有稳定形式，连续重复会单调，每页完全不同会丧失整体性；可用图片尺度、留白、章节区分及材料控制节奏。跨媒介应从一开始考虑，纸张、屏幕和包装的阅读条件不同。

`[综合]` 先固定识别骨架，如字体角色、栏目标签、标题对齐与图注方式；再指定允许变化的变量，如图幅、密度、跨栏和章节入口。把整组页面排成缩略总览，检查连续高密度页、重复焦点和突变。技术参数、价格及比较信息宜保持可比结构；情绪导入可以更自由。

`[现代补充]` 网页的响应式重排还要保持语义顺序、焦点顺序及触控可达；需要时与 项目已有的中文 UI 工作流（如可用） 联用。纸上从左到右的跨页引导，不证明滚动网页也应如此。F形浏览只是内容与用户条件下的假设，不作为所有布局的硬规则。

## 5. 一份内容繁多的社区活动海报

`[综合示例，数值均为试排起点]` 假设面向社区居民，目标是“知道是什么 → 找到感兴趣活动 → 核对时间地点 → 报名”。标题不超过两行，3项活动各有名称、约30字说明；另有举办时间地点、截止日、真实报名码。没有照片也可用纯文字完成。

**手机转发版：** 先试1080×1440px，边距64px，版心952px。以两栏、24px栏距建立对齐，标题与3项活动均跨两栏；底部一栏为时间地点与截止条件，一栏为报名码与说明。标题先试80px、活动名44px、正文与日期38–42px、行高约1.45；较长内容让区块增高，必要时增加画布高度或另出详情图，不能为了1440px而缩到不可读。二维码先留220–260px区域，保留生成器要求的静区；手机同屏操作要说明“长按识别”或提供另一路径。聊天缩略预览只要求主题和活动性质清楚，打开后要求必要信息可读。

**A3打印版：** 297×420mm。先试左右边距15mm、版心267mm，3栏、6mm栏距，每栏85mm。标题跨3栏，时间地点紧随其后，3项活动分别占一栏；底部把报名区与截止信息组成一个稳定组。标题先试38–46pt、活动名18–22pt、说明12–14pt，按实际张贴距离调整。二维码先试30mm并以真实内容扫码；出血先按3mm沟通，最终服从印厂规范。不能把手机版等比缩放当成打印版完成。

**验收输出示例：**

| 位置与证据 | 问题、改法及取舍 | 动作与通过条件 |
| --- | --- | --- |
| 手机正文，未试排 | 源字30px缩到360px宽仅约10px显示，先升到38–42px并增加内容高度 | 最终图在常用手机打开、正常缩放查看，活动名、日期地点完整可辨，无放大才能找到的信息 |
| 三项活动，待渲染 | 长短内容造成对齐混乱，统一名称与说明字段，保留自然高度 | 真实最长文案无溢出，阅读顺序明确，不依赖三块同高 |
| 打印报名区，待打样 | 二维码清晰度与静区未知 | 从最终PDF和A3样张扫码，正确进入报名页；裁切不损码与说明 |

## 6. 生产与证据

材料、装订和裁切从设计初期考虑；文字校对、颜色校样与最终成品各检查不同问题。

`[现代补充]` 印刷位图按最终放置尺寸计算有效PPI：`像素宽÷(放置宽mm÷25.4)`。所需密度依工艺和观看距离与印厂确认，线稿/二维码优先保留矢量；改变dpi元数据不能增加细节。色彩配置、出血、字体嵌入或转曲、PDF规范依接收方确认；保留可编辑母版，转曲文件另存。是否转曲取决于接收方实际工作流。

实际制作后记录文件、版本、观看尺寸、截图或样张、发现与修正；只做建议时填写验收计划，不填写虚构通过记录。整体缩略、正常阅读与细节放大三种尺度分别有证明范围。

## 来源卡与两层分类

**编写者综合。** 对核心参照记录下列信息，不必逐个装饰点填写长表。

| 字段 | 内容 |
|---|---|
| 定位 | 参考图、原物或作者、可靠链接与图像版本 |
| 对象 | 几何/植物/动物/文字/复合母题；实际载体及边界 |
| 可见结构 | 主轴/主势、格网、对称、旋转、平移、连接、疏密、正负形 |
| 历史证据 | 朝代/地域/原物/工艺是否有图注或可靠记录；没有就写未确认 |
| 使用状态 | 只读参考、适用许可下直接使用、自有原创、待核范围；声明不清楚时记录待核范围 |
| 本次变化 | 保留的通用关系、新画的母题、组织和实际尺寸；与参照的差别须真实 |

将任务拆成母题与组织两层，避免混淆题材与应用场景：

| 层次 | 选择与用途 |
|---|---|
| 母题 | 几何靠角度、节距与连接；植物靠主茎、分枝、叶花节奏；动物靠身体主势、头肢识别与轮廓；复合图形先定主次 |
| 组织 | 自由单体独立识别；适合纹样依圆/方/三角/器物轮廓重新组织；二方连续沿一轴延伸；四方连续沿两轴铺展 |

“适合”不只是把图塞进蒙版。边界、中心、转角和留白参与构图；从圆框换成狭长杯带，通常要重画主势与间距。历史复原另核原物记录，不能从现代参考图风格猜朝代。

## 从图版提炼骨架

从参考形态寻找可迁移的关系，再针对本次任务重画母题与组织。

| 形态观察 | 可迁移的关系 |
|---|---|
| 格网、六角单元、斜向线与植物图形并用 | 把格网与母题分层；先看接点，再改变填充或省略线段，别只换一个花色 |
| 多条边饰中有较宽动物带与窄几何带 | 建主带与辅助带的宽度层级；窄边饰不能与主母题同样繁密 |
| 蝴蝶既有近对称，也有倾斜姿态与装饰性翅部 | 区分识别轮廓和内部纹理；系列可以保留共同轮廓，改变姿态及填充 |
| 鸟有简轮廓、实心剪影和复杂羽饰 | 同一题材可有不同细节等级；小尺寸先保轮廓与负形 |
| 龙的长身曲线、头肢及繁密鳞须，存在完整独幅构图 | 先设计主势线与识别特征，再决定细节预算；独幅完整不代表可以周期接边 |
| 圆形、方形、横向的动物植物组合 | 边界改变会改变构图；框内填满与连续平铺是两种任务 |
| 动物式曲线/正负形交替形成连续关系 | 先约定单位和变换；检查旋转、方向与间隙是否共同形成节奏 |
| 水纹有平行层线、卷曲浪头、单簇与横向带 | 选择流向、密度和层数；单簇水纹不必强行拉满全幅 |
| 圆/方/三角框、长条及角部建筑图形 | 边界适配、轴线与角部有明确作用；装饰构件的形状不是可随意切割的平铺单位 |

落笔顺序：用少量线画主轴/主势 → 标出重复节距与大空隙 → 画轮廓并看黑白剪影 → 补一层关键内纹 → 在最小使用尺寸删减。保留必要识别特征，但不能用“改若干节点”替代独立创作或许可核对。

系列设计先固定格网/主势、线宽等级与一种间隔关系，再选择一两个变量：单位、方向、尺寸、密度或正负反转。不是所有款式都必须对称，也不是越满越传统。

## 连续组织与 SVG

本节为**现代矢量制作补充**，具体规范仍由实际文件与工艺验证。

### 选重复规则

- 二方连续：定义节长 W，沿水平方向按整数倍 W 平移；若是竖带则用高度 H。端点接续、母题朝向与空隙周期共同检查。
- 四方正排：定义 W×H 单元，按 `(mW,nH)` 平移。跨左边的图形副本向右平移 W；跨上边的副本向下平移 H，反向同理。穿过角落时补齐横向、纵向和对角副本。
- 半落位示例：每隔一列向下错 H/2，下一列回到同一周期；用2W×H矩形超单元检查。不要把斜着挪的一格误当已经形成完整周期。其他错位按实际规则另定周期。

接边不只看“坐标相同”。持续穿越边缘的曲线应核对端点、切向和线宽；色块、背景、叠印和透明度也要一致。自然的尖角可保留，不强行把所有连接变光滑。

### 制作与检查

1. 保留可编辑单元及母题，不靠导出后补像素掩盖几何问题。统一单位、`viewBox`与重复宽高；要导出铺排时确认使用的是主单元还是超单元。
2. 用准确平移复制跨边对象，再以单元边界裁切；不要手动缩放对应副本。必要时保留足够的裁切外图形，避免描边在边缘被误截。
3. 查看3×3及更大如6×6的阵列：前者查四边四角，后者查意外直线、斜带、空洞和密度聚集。方向性按任务判断，有明确上下的图案不需伪装为无方向。
4. 缩放至最小使用尺寸、黑白与反白状态，检查头肢、花蕊、转角和窄缝。发现细节堆糊，先删内纹或调整间距，不无限加粗所有线。
5. SVG 交付核对填充规则、开放路径、描边端点、裁切、隐藏/重复对象与外链。缺少原始位图或字体不能造成文件打开缺图。保持可编辑母版；供应方要求轮廓化时另导出版本，并再次看图。
6. 不把节点越少越好当唯一目标。简化后须比较轮廓和转折；输出实尺预览及单元规格说明。没有实际渲染查看，不能声称无缝和生产可用已通过。

## 商品龙纹方案示例

**现代应用提议。** 用户持有一张龙纹参考图，准备描成商品图案，尚未提供商品刀模和适用许可。

可以先交付原创概念，不把全部工作停在询问授权。给出两条明确路径：已取得适用许可则按目标图及允许用途整理矢量；条件未明则保留参考图作为结构研究，改为自行设计新龙形与组织。不能用“古代题材”替代对具体素材的核验。

**原创结构方案。** 先以200×200设计单位作草稿，假定最终重复为20×20mm（均为本例可调整参数）。画一条斜向 S 主势，自行设计角、头、四肢与尾部的比例和转折，先不画鳞片；以两簇自画云形平衡负形。龙头和关键爪留在单元内部，云或尾段可跨边，精确平移对应副本。以整体曲线节奏组织疏密，不沿描某幅图版后只换颜色。题材含义写“本次借龙的上扬动势表现活力”，不声称该画法属于某朝宫廷制度。

**输出。** 一份来源/使用说明；母题与骨架草图；可编辑 SVG 母版及200×200单元；3×3和6×6预览；最小成品尺寸稿；待供应方确认的线宽、负形及色层项目。没有制作文件时这些是计划与规格，不冒称已有 SVG 或预览。

**成品适配。** 平面包装用实际刀模，避开粘口、折线和主要文字；圆柱杯带先取得可印周长 C，选整数重复数 N，单元宽为 C/N，检查环周首尾相接。杯体有锥度时使用真实展开模板和生产补偿，不能把矩形强行拉成圆环。20mm草稿不得直接当所有杯子的通用单位。

**实尺修正。** 先试轮廓版与一层内纹版，对比头肢能否辨识；鳞片/须线在实际工艺下糊连时删减。供应方未给线宽指标或未见实物时，标为概念可用、生产待确认；不编造“SVG无限缩放所以一定清楚”。

## 缩放、实物与验收

| 检查 | 通过条件与证据 |
|---|---|
| 来源与叙事 | 关键图案的参考和使用状态可核对；年代、寓意、身份不靠风格猜测；现代方案有明确标记 |
| 单元与周期 | 尺寸、方向和变换规则可复述；所有对应边/角一致，持续线无意外断口、重线或突变 |
| 大面积节奏 | 阵列中无无意形成的条带、局部拥挤或大洞；希望有方向/节奏时能说明作用 |
| 识别与缩放 | 最小目标尺寸仍识别主母题；轮廓、线宽与负形不混为一块；必要时制作不同细节等级 |
| 实物适配 | 折边、接缝、弯曲与视角不破坏关键识别；与真实文字/标志同时排看，装饰不盖内容 |
| 工艺样品 | 按目标纸张/织物/陶瓷贴花/雕刻等确认最小线宽、间隙、套准和表面效果；设计稿与实样逐项比对 |
| 文件 | 独立打开无丢图，尺寸/颜色模式及输出规格明确；母版与生产版分别保存，实际查看导出结果 |

只完成文字方案时列出待制作/待测项。完成文件后应实际查看平铺图及实尺预览；成品验收需要目标材料样品，不能由路径检查代替。配色涉及传统色名时按需读取[传统色专题](../traditional-color/guide.md)，不让“国风”自动限定成同一套低饱和色。

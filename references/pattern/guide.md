# 传统纹样：从骨架到实物

先理解母题、组织规则与使用边界，再制作能接边、能缩放、能在目标材料上辨识的图形。题材传统，不代表某一现代描绘可以任意复制。

## 入口与边界

- 首次执行读 [方法与验收](methods.md)；查图集案例、页码与证据限制读 [来源](sources.md)。引用页码均为实际 PDF 页序。
- 本专题负责图形骨架、单元变化、连续组织、矢量与实物适配；配色文化交给 [传统色专题](../traditional-color/guide.md)，中文网页排版和交互交给 项目已有的中文 UI 工作流（如可用），跨艺术作品的观察与迁移可用 [艺术分析专题](../art-analysis/guide.md)。
- 来源文件不在环境时，可用已记录的图版观察继续做原创方法方案；不能假装看过用户未提供的目标纹样，不能编造编号、年代、出处与授权条款。

## 工作流程

1. **明确对象。** 提取受众、载体、成品尺寸/刀模、工艺、单向或多向观看、当代借鉴或历史复原。缺省先做当代原创概念，列出合理假设；关键生产尺寸未定时仍能完成骨架和比例草案。
2. **记录来源与使用状态。** 保存书名、实际页、图号、可见结构、作者/原物信息和可用权限。图集 PDF 的阅读权限、附赠矢量下载与商品印制许可分别核对。权利不明时继续提炼通用组织方法并自行设计母题，不交付原页描摹成品；用户已有适用许可时按许可制作，无须重复审批。
3. **拆两层分类。** 先分几何、植物、动物/瑞兽、文字、复合母题；再选自由单体、适合纹样、二方连续或四方连续。器物、织物、建筑是应用场景，与母题类别不同。不能把一个完整团龙框图直接称为无缝单元。
4. **先画骨架。** 记录轴线、格网、主势、对称/旋转/平移、疏密和正负形，再补轮廓及内部细节。为系列固定少量规则，改变单位、方向、填充或间距。用书中图案讨论结构时，将“可见观察”与“历史寓意”分开。
5. **组织与接边。** 选定单位尺寸及重复方式，跨边图形用准确平移生成对应副本；四角同样处理。检查接点、切向、线宽、色层和背景，不用肉眼挪近代替连续。错位/半落位用完整周期或超单元验证。
6. **矢量与实物验证。** 输出可编辑母版、独立单元、平铺预览及成品尺寸模拟。查看3×3局部和更大阵列的节奏，再按实际尺寸/曲面/折边打样；技术上接缝消失不等于重复节奏自然或量产可行。

## 必须保留的判断

- 本地图集是现代整理与绘制的应用参考，前言明说未考究历史文化背景；不据其编号认定“明代正统龙纹”或替所有水纹赋同一寓意。
- 改色、镜像、简化节点和转成 SVG 不自动解决现代图版的使用权限。古代母题、具体文物图像、现代重绘与书籍编排分别判断；来源不明就如实标明。
- 无缝图案须满足周期关系。四方连续不要求每个母题都在画框内完整，也不要求镜像；重要头部、文字等若不宜断开，调整排布而非强行裁切。
- SVG 的无限放大能力不能替代生产检查。细线、窄缝、叠墨、刺绣针距、雕刻深度等以目标工艺样品与供应方指标验收，不编通用最小毫米数。

## 例子与完成条件

请求：“把手上图集的龙纹描成 SVG 印商品，并做无缝。”

先定位目标页与使用范围；未证实商业使用条件时，提供原创龙形与云纹的结构方案，保留授权直接使用的后续路径。参考 P1 PDF98、111 观察长身主势与内外细节，PDF104 的框内构图与 PDF106、120 的连续组织作比较；不能把这些现代图版直接描入商品。用自绘主势线设计新母题，建单位、准确平移跨边副本、查四角、看3×3和大阵列，再做实尺与成品接缝样。完整示例见方法文件。

通过条件：来源与使用状态明确；骨架、重复规则、单元尺寸可复述；四边/四角无断裂和异常空洞；大阵列无意外条带；实尺识别、线宽、负形、曲面或折边适配经查看，未打样则明确为待验证。

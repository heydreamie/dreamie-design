# 传统色：事实与材料核验

- 历史复原优先核对原始文献、博物馆藏品记录、工艺档案或可靠检测报告；同一转述的重复出现不算独立证据。
- 记录色名异体、材料、用途、时代、地域和证据性质；未确认的内容明确标记。
- 古籍提及色名可以支持语义和使用语境，不能单独证明唯一的现代数字值。
- 数字设计、图像采样、材料实测分别记录，不把当代颜色候选说成古代标准。
- 同名异色保留差异；釉色、纤维、颜料、表面光泽、光源与老化都需按对象判断。
- 当代品牌创作可以继续制作概念稿；文化叙事不得把设计联想装成历史结论。
- 实物输出使用目标材料打样，保留样号与查看条件。

具体方法见 [methods.md](methods.md)。

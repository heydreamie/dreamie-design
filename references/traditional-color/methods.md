## 证据卡与来源优先级

核心颜色使用下列字段，不必为项目所有辅助灰逐一考据。

| 字段 | 要记录的内容 |
|---|---|
| 名称 | 原字、异名、同名不同义；OCR 不确定字须看图 |
| 对象 | 织物、釉、颜料、木材、金属、自然景色等 |
| 材料/工艺 | 本色、染色、套染、矿物研磨、烧制、涂饰；原页没有则标未确认 |
| 语境 | 时代、地域、阶层、宗教、文学或民俗；不用一种语境概括整个时代 |
| 出处链 | 本专题来源编号 → 书/章节 → 实际 PDF 页 → 书内引据或访谈对象 |
| 证据状态 | 原页可见、本书转述、作者推测、跨书综合、现代应用；可多选 |
| 数字与材质 | 书载 RGB/CMYK、图像采样或本次设计值；配置文件/光源/底材是否已知 |

本地三书是应用与研究入口。严格复原服制、文物色或某时期工艺时，继续核原典、馆藏实物记录及科学检测资料；不要将三书之间相同的转述当成三份独立证据。用户只要当代方案时，不必把任务升级成论文。

## 从书页提炼可用关系

以下“书内证据”均为对原页的短摘要；“设计转译”是本专题的综合方法。

| 书内证据与检索页 | 设计转译 |
|---|---|
| C1 PDF39–40：胭脂的植物材料、妆饰与绘画用途，讨论久后走色 | 红色的身份要附着于用途；需要耐久生产色时另选现代材料，并如实命名 |
| C1 PDF65–68：栀子果染织物、黄檗染纸 | 不把“黄色”只解释成皇权；按织物/纸张选择文化叙事 |
| C1 PDF93–94、116–117：靛染、重复浸染与浅深层次 | 一色多阶可构成主辅系统；不要用一个屏幕蓝抹平染法与深浅 |
| C1 PDF102–103、131、134：石青/石绿矿物用色及颗粒/分级叙述 | 粉体、透明度、覆盖力与颗粒影响视觉；数字色相只是表层 |
| C1 PDF174–175：香/秋香的香染、僧服及后续服饰文化；含明代织锦图注 | 选择“衣饰”“宗教”“材质”中与品牌相符的一条线；图注不能证明全明代通行 |
| C3 PDF12–16：竹炭加入陶土的炭陶，与烟熏吸附的黑陶有区别 | 黑色方案需同时描述亚光/亮光、均匀/变动和工艺，不只给一个黑色号 |
| C3 PDF29–33：油烟与松烟、墨色浓淡干湿等变化 | 通过材质与层次构建丰富黑灰；“墨分五色”不是五个固定 HEX |
| C3 PDF185：八工针法改变蚕丝光泽、呈现青铜器的亚光质感 | 纤维方向与表面处理也参与配色，不能由色卡替代实物观察 |
| C3 PDF217–229：青白釉、坑烧、龙泉青瓷的不同形成过程 | 茶器先区分釉色与胎体/烧痕；屏幕概念色需交给实际烧成样验证 |
| C2 PDF11–13、86：色相/色调、同类/对比/间隔与清浊，以及不等面积组合 | 学习组织关系，重新设计符合项目的组合，不复制整页成品纹样 |
| C2 PDF125–172：二十四节气的当代色群与意象设计 | 可借季节冷暖/物候形成系列；标为该书与本次设计表达，不称古代节气标准色谱 |

关系提炼可以用“主色的明度与纯度 → 与背景的距离 → 强调色面积 → 中性色桥接 → 材质反射”五项检查。配比按用途决定，60/30/10 等比例只是一种草稿工具，不是传统法则。

## 数字化与媒介验证

### 同名异色

已核原页的“天青”对照：

- C1 PDF114：印刷参考 C65 M0 Y6 K0，图版偏鲜天蓝；PDF115 延展到服色与柴窑传说。
- C2 PDF85：参考 RGB195/224/231、CMYK27/4/9/0；如将其 RGB 作为 sRGB 应用假设，HEX 为 `#C3E0E7`。这是现代手册的数字参考，RGB 原页未明确配置文件，不称测得的古代 sRGB。
- 二者不应强行取平均。先明确选择的是自然天色、某书版本还是某件具体釉器；复原器物时回到实物与测量条件。

只给出一个色号不能描述釉面透明度、金属光泽、蚕丝方向和染料老化。避免未指定 ICC 的 CMYK↔RGB 数学换算被误称“精准还原”；确需概念预览时明确其近似性质。

### 实际应用检查

- **屏幕**：保存 sRGB 预览，检查整版面积与灰度层级；文字与背景按当前适用的可访问性要求实测，传统色不豁免可读性。UI 实现按[共同验收](../acceptance.md)检查；已有中文 UI 工作流可选联用。
- **纸与包装**：实际纸张、油墨、涂层、印刷条件打样，记录样号；自然光与预期销售灯光下看色偏、反光与字迹。CMYK 数字不能代替签样。
- **茶器与工艺品**：分别记录胎体、釉、表面光泽、烧制条件与样号；同光源下比较实物，必要时使用色差仪并约定指标，不默认本专题已完成测色或量产验证。
- **织物**：用目标纤维、组织、染法与后整理打样，查看折叠、垂坠、透光与不同方向；需要牢度时采用生产方的检测方案。

## 茶器品牌示例

**输入**：喜欢天青、胭脂、秋香，希望明代气质，有茶器和纸盒。

**合理默认**：当代品牌借鉴明代意趣；若用户明确要求文物复原，则切换到考据任务。

### 可交付方案

| 角色 | 方案 | 依据与状态 |
|---|---|---|
| 主色 | 浅天青用于盒面或网页大面 | 可从 C2 PDF85 的 RGB195/224/231 开始；本书现代参考，sRGB 为应用假设 |
| 重点 | 胭脂红用于封签/小面积标识 | C2 PDF29 的 RGB151/40/50，可作为 `#972832` 概念参考；C1 PDF39–40 为材料与文化检索入口 |
| 辅色 | 秋香用于纸带或器物附件的小面 | C1 PDF174–175 提供香/秋香语境；先以黄棕方向选实际纸样，不虚构唯一古代 HEX |
| 功能色 | 深灰字与纸本底色 | 本次应用选择；需要实测可读性，与历史色名分列 |

这不是证明明代曾把三色组合成某一标准。C1 的香色叙述与 C3 PDF57 的当代木作“香色”也不能混成同一种染法。

**短文案**：“以一抹浅青盛清意，以胭脂点醒日常，秋香收住纸上的暖。让手中的一盏茶，有可亲近的古意。”标注为当代品牌创作，无须冒充古人原话。

**样稿验收**：用同一纸盒结构比较两种天青版本；查看主色是否压过器物照片，红色封签是否可辨，秋香与纸本底是否混在一起；保留选定纸样与实物茶器的并置照片。未烧成/未印刷时交付状态写“概念稿，待材料打样”。

## 常见误判与验收

| 误判 | 改法 |
|---|---|
| 五色观 = 现代 RGB/CMYK 原色理论 | 说明它们属于不同知识体系，不把书中类比当科学等同 |
| 将“传统”一律改成低饱和灰绿 | 依据任务与来源决定；年画与节庆也可用鲜艳、强对比 |
| 古籍诗句提到色名，所以能确定色值 | 诗句可证语义/意象，测色需要另一类证据 |
| 图片有明代图注，所以整段文化都属于明代 | 分开图注年代、作者解释、所引文献年代 |
| 天然材料意味着当前产品安全、可直接复配 | 材料史只支持解释；生产需适用材料与供应方验证，历史含汞/铅/砷材料不作为消费品复配建议 |

通过条件：核心色证据链可追溯；借鉴与复原模式清楚；数字来历可解释；故事不把当代感受装成史实；输出含实际媒介的验收方法与未验证状态。

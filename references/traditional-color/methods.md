# 色名、材料、文化与当代配色

## 1. 证据卡与来源优先级

核心颜色使用下列字段，不必为每个辅助灰逐一考据。

| 字段 | 要记录的内容 |
|---|---|
| 名称 | 原字、异名、同名不同义；辨识不确定时查看原始图像 |
| 对象 | 织物、釉、颜料、木材、金属、自然景色等 |
| 材料与工艺 | 本色、染色、套染、研磨、烧制、涂饰；没有证据则标未确认 |
| 语境 | 时代、地域、用途与人群，不用一种语境概括整个时代 |
| 依据 | 可靠文献、馆藏记录、工艺档案、检测资料或明确的项目选择 |
| 证据状态 | 直接记录、转述、解释、当代应用、待核验分别标记 |
| 数字与材质 | 颜色空间、取值方式、光源、底材及配置条件 |

严格复原服制、文物色或工艺时，优先核原始文献、实物记录及检测资料。同一转述的重复出现不算独立证据。只要当代方案时，先完成设计，不把任务无故升级为研究论文。核验边界见 [sources.md](sources.md)。

## 2. 从材料关系到设计关系

| 观察对象 | 可执行的设计检查 |
|---|---|
| 染织的深浅与层次 | 用一色多阶组织主辅，不以一个数字抹平材料和工艺差异 |
| 颜料的透明、覆盖与颗粒 | 区分色相和表面质感，不靠增加纸纹代替材质观察 |
| 光泽、纤维方向与涂层 | 同一颜色分别查看哑光、亮光、折叠与不同方向 |
| 釉、胎体与烧痕 | 将颜色和器物结构一起设计，再用真实样品确认 |
| 季节与物候意象 | 可形成当代系列，但不称为古代标准色谱 |
| 色名的文化联想 | 只选择与品牌有关的语境，不把情绪联想写成制度或史实 |

关系提炼可按“主色明暗与彩度 → 与背景的距离 → 强调色面积 → 中性色桥接 → 材质反射”检查。配比由用途决定，60/30/10 等仅作草稿工具。

## 3. 同名异色与数字化

同名颜色在不同记录、材质和数字化条件下可能不同。先明确选择的是自然景色、某件器物、某个可靠版本还是本次数字设计；保留差异，不强行取平均。

一个色号不能描述釉面透明度、金属光泽、蚕丝方向和老化。RGB/HEX 注明颜色空间与用途；CMYK 注明印刷条件。没有 ICC 的换算只能作为近似预览，不能声称精准复原。

当代概念可以选择合适数字：例如浅青 `#C3E0E7` 与深红 `#972832` 作为一组 sRGB 候选。即使分别命名为“天青方向”“胭脂方向”，也不代表历史上只有这两个标准值，更不等于实物材料已匹配。

## 4. 茶器品牌示例

输入：希望以天青、胭脂和暖纸色形成有古意的茶包装。默认按当代品牌借鉴处理；明确要求文物复原时改用对象证据与实测。

| 角色 | 方案 | 状态 |
|---|---|---|
| 主色 | 浅青用于纸盒与罐体大面 | 数字概念先看整版面积，材料待打样 |
| 重点 | 深红用于封签或小面积标识 | 与浅青形成对照，检查强调是否过量 |
| 辅色 | 暖纸色用于纸带、内衬或背景 | 依据实际纸样选择，不虚构古代唯一值 |
| 功能色 | 深灰组织标题和说明 | 实测文字与背景可读性 |

短文案可写：“以浅青盛清意，以胭脂点醒日常，让一盏茶有可亲近的古意。”这是当代品牌创作，不冒充古人原话或历史记载。

用同一包装结构比较两套颜色关系，查看红色封签、文字和材质反光。保留选定纸样与实物器物的并置照片；未印刷、未烧成时交付状态为“概念稿，待材料打样”。

## 5. 分媒介验证

- **屏幕**：保存适合目标环境的预览，查看整版与灰度层级；文字仍须满足适用的可读性要求。网页按[共同验收](../acceptance.md)执行。
- **纸与包装**：使用真实纸、油墨、涂层与印刷条件打样，记录样号；在预期使用光源下看色偏、反光和字迹。
- **茶器与工艺品**：记录胎体、釉、表面、烧制条件与样号；必要时按约定指标测色，不默认已完成量产验证。
- **织物**：用目标纤维、组织、染法和后整理打样，查看垂坠、折叠、透光与方向；牢度由适用检测确认。

## 6. 常见误判

| 误判 | 改法 |
|---|---|
| 五色观等同现代 RGB/CMYK | 区分知识体系，类比不能当科学等同 |
| 传统色只能是低饱和灰绿 | 按语境与任务选择，不能机械限制配色 |
| 诗句提到色名就能确定色值 | 语义证据与测色证据分别处理 |
| 一张图的年代说明能覆盖全部叙事 | 分开对象年代、解释与其他材料的年代 |
| 天然材料一定安全且能直接复配 | 生产按适用材料和供应方验证；材料史不作为消费品配方 |

通过条件：历史主张可核验，借鉴与复原模式清楚，数字用途可解释，文案不把当代感受装成史实，媒介验证与待完成项真实。

# 中国传统色：从出处到应用

把色名放回材料、工艺、时代与用途中，再确定适合当代媒介的颜色。历史色名不是跨时代不变的数字标准。

## 使用与边界

- 色名释义、文化故事、历史取色：先查 [sources.md](sources.md) 的书目和页码索引，再按问题回看原书相关完整页。
- 品牌、包装、器物与服饰配色：读 [methods.md](methods.md)，输出有来源的配色关系及打样方案。
- 中文网站落地由 项目已有的中文 UI 工作流（如可用） 处理字体、组件、响应式与交互；本专题提供色彩依据，不用古意覆盖可读性需求。纹样的骨架、连续组织与矢量制作属于 [纹样专题](../pattern/guide.md)。
- 来源 PDF 不在当前环境时，使用本专题已记录的证据摘要；说明尚未回看原页，不能编造新增引文或页码。

## 工作方法

1. **定位语境。** 从用户已有信息提取时代/地域、使用人群、器物或材料、输出媒介，以及“历史复原”还是“当代借鉴”。缺省按当代借鉴推进，明确假设；只有决定方向的缺口才提问。
2. **建立证据卡。** 每个核心颜色至少保留：色名与异名、材料/工艺、时代或使用语境、书名与实际 PDF 页码、证据性质。没有材料证据就写“未确认”，不根据名称反推配方。
3. **区分三层。** `书内证据`是本书所述，古籍故事仍可能只是本书转述；`综合判断`说明跨书比较；`现代应用`包含角色、面积、数字色值和品牌文案。对“相传、据说”保留其不确定性。
4. **先关系后数字。** 比较明度、纯度、冷暖、主辅关系和材质光泽，选择一版有出处的参考；同名异色保留并解释。RGB/HEX 标明色彩空间与“现代参考/书中参考/本次打样”，CMYK 记录所用印刷条件；没有配置文件时不假定可唯一换算。
5. **交付可验证方案。** 提供色彩角色、出处简表、一段可用文案，以及与媒介对应的实测/打样动作。复原任务另列未核证处；概念稿不用等待考据全部完成。

## 必须守住的判断

- 不能给“唯一准确的古代 HEX”，不能凭三本通俗设计书宣称“某朝最正统”。书内印刷示例不是古代标准，也不是出土物测色报告。
- 同名不代表同色，同色不代表同材料。同为黑色，要分墨、漆、炭陶、烟熏黑陶；同为青色，要分自然景物、织染、颜料与釉色。
- 文化联想不自动成为史实。写“本次品牌借其清润之感”可以；写“明代人人以此为最高礼色”需要对应的制度与场景证据。
- 扫描图受印刷、扫描、压缩和显示影响；吸管得到的是该图像像素，不能称古物本色。也不将现代访谈中的产品功效或工艺配方直接作为已验证生产指标。

## 例子与验收

请求：“明代茶器品牌用天青、胭脂、秋香，给最正统古代色值。”

先说明按“明代意趣的当代品牌”处理。天青可比较 C1 PDF114–115 与 C2 PDF85 的不同示例；胭脂查 C1 PDF39–40 的植物用料与妆饰/绘画语境；秋香查 C1 PDF174–175 的香染与服色叙述。使用 C2 数字值时标作该书现代参考，不把三色并用说成明代制度；给打样与文案，而非止于纠错。完整示例见方法文件。

验收：每个历史主张能返回具体页；每个数字有来源与用途；文案能区分古籍转述和当代创作；实际应用中主次清楚、文字可读、材质打样及未验证项如实标注。

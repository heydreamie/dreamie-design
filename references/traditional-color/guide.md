# 中国传统色：从语境到应用

把色名放回材料、工艺、时代与用途中，再确定适合当代媒介的颜色。历史色名不是跨时代不变的数字标准。

## 使用与边界

- 色名释义、文化故事、历史取色：读 [sources.md](sources.md)，按问题核对可靠文献、馆藏记录或检测资料。
- 品牌、包装、器物与服饰配色：读 [methods.md](methods.md)，输出有主次的配色关系和媒介验证方案。
- 中文网页按项目已有的 UI 工作流处理字体、组件与交互；纹样的骨架与连续组织见[纹样专题](../pattern/guide.md)。
- 尚未取得核验材料时，可以先做当代概念；事实性主张保持待确认，不编造引文或历史归属。

## 工作方法

1. **定位语境。** 提取时代/地域、受众、材料、媒介，以及历史复原还是当代借鉴；缺省先按当代借鉴推进。
2. **建立证据卡。** 记录色名与异名、材料/工艺、使用语境、可靠来源和证据性质；不能按名称反推配方。
3. **区分事实与创作。** 实物记录、文献转述、分析判断和现代应用分别标记。“相传、据说”保留不确定性。
4. **先关系后数字。** 比较明暗、彩度、冷暖、主辅和光泽。同名异色保留差异；数字注明颜色空间、取值方式和用途，CMYK 记录输出条件。
5. **交付可验证方案。** 给出颜色角色、文化叙事、具体应用及打样动作。历史复原另列未核事实；概念稿可先完成。

## 判断边界

- 不给“唯一准确的古代 HEX”；印刷或数字示例不等于古物测色报告。
- 同名未必同色，同色未必同材料；自然景物、织染、颜料和釉色分别判断。
- 文化联想不自动成为史实；品牌可以表达清润、温暖等当代感受，制度与年代主张需另证。
- 图像取色只反映文件像素；不能当作古物本色或已验证的生产配方。

## 应用与验收

用户希望以天青和胭脂设计茶包装时，先按当代品牌处理：浅青作大面积底色，深红作封签强调，深灰保证文字可读。实际数字为项目候选，不证明历史唯一标准。若明确要求复原某件器物，则回到该器物的材料记录、实测与样品。

验收：事实可核验，数字有来历与用途，文案区分历史与创作，实际画面主次和文字清楚，材料打样及待验证项如实标记。
